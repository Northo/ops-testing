# Playground for operations tooling

Tools currently used:

### Renovate

Dependabot alternative, see https://docs.renovatebot.com.

Example:

> Installed an older version of requests (`2.31.0`).
> This immediately triggered Renovate to make a PR with an update, https://github.com/Northo/ops-testing/pull/3.
> At https://github.com/Northo/ops-testing/issues/2 one can at all times see an update view of the status.
